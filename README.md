# Travel Dreams Website

A multi-page website about the places I dream of traveling to someday, and the books I love.

## Pages

- **Home** (`index.html`) – About me, my hobbies and interests.
- **Travel Destinations** (`about.html`) – My top three dream destinations: Toronto, Mecca and Bali.
- **Travel Destination Info** (`information.html`) – More details about each destination, with links to learn more.
- **Books** (`books.html`) – My favorite book genres and series.

## Built With

- HTML
- CSS (gradient backgrounds, hover effects on the navigation, styled content boxes)
